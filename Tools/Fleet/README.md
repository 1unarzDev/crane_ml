# Tools/Fleet (engineering subset)

The modular mecanum rover design and its shared libraries, published on their own:
- `assets/`: rover asset generator and validator (v0 provisional) and the concept-matched parametric CAD v1, in `assets/cad_v1/` (build123d parts, per-role URDFs, design plan and log, comparison sheets).
- `spec/`: fleet profiles v0 and v1, scenarios, module types.
- `core_cs/`: C# docking, perception, capability and autonomy libraries, with tests.

All values are provisional, concept or datasheet level. Nothing is measured on hardware.
