## Scaling laws (log2 N slope per doubling, 95% CI; full table section 3)
- **Value of the shared plan (IMPLICIT - INDEP):** grows with N in every condition.
  - Healthy: +0.07 to +0.15 per doubling. At N = 10 INDEP is 0.29-0.47 below IMPLICIT.
  - Power-law exponents b ~ -0.5 to -0.8, i.e. it grows like N^0.5-0.8.
- **Stale-plan penalty (IMPLICIT - HYBRID), healthy:**
  - travel 0: ~linear in N (b ~ -0.9 to -1.1), +0.08 to +0.12 per doubling;
  - travel 1: +0.01 to +0.02 per doubling.
- **HB_TO false alarms, healthy bursty link:** the cost grows ~ N^1 (b -0.8 to -1.25), reaching -0.09 to -0.13 at N = 10.
  - On ideal/d1 HB_TO == IMPLICIT exactly when healthy, and == HEALTH under perm.
- **Healthy VoC (ORACLE - IMPLICIT):** slope CIs all include 0. There is no scaling trend; the sign depends on the environment.
- **Loss VoC (ORACLE - IMPLICIT):** slope -0.0004 to -0.015 per doubling, every CI including 0.
- **HEALTH - IMPLICIT under loss:** -0.015 to -0.047 per doubling, every CI excluding 0. The beacon's benefit declines with N and reverses by N = 5-10.

## What generalizes / what does not
- **Generalizes across N, both travels and both lam:**
  - The shared default plan matters more as teams grow.
  - Mixing fresh messages with a stale plan is a hazard that grows with N, strongly without travel.
  - Healthy-team VoC stays small in magnitude: |ORACLE-IMPL| <= 0.037 everywhere.
- **Does NOT generalize from N = 2:**
  - (a) "One HEALTH frame recovers the loss gain" holds only at N = 2. At N >= 5 it hurts.
    - Mechanism (not tested here): all N-1 survivors learn of the death simultaneously and herd into the dead agent's cells.
  - (b) The priority-order role rule (HYBRID_P) no longer restores parity at N >= 3.
  - (c) The VoC under loss does not follow a clean 1/N law. At travel 0, centralised knowledge regains value at N = 10.
  - (d) "Communication has no value" is not uniform. With travel, lam 3 and N >= 3, a centralised greedy planner is significantly worse than silence; without travel, lam 3 and N = 10, it is significantly better.
