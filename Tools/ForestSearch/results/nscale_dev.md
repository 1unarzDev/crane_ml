## 2. Dev effect sizes (point estimates at N = 2, 3, 5, 10; full tables in §4)

- **S1: healthy ORACLE − IMPLICIT.**
  - Travel 1, λ=1: −0.01, +0.01, −0.03, −0.05.
  - Travel 0, λ=1: +0.03, −0.05, −0.05, −0.03.
  - All values are within ±0.06 and none is significantly positive. At N = 10 the sign leans *negative*, i.e. a centralised greedy planner is no better than the shared plan. This matches the prereg's stated alternative.
- **S3a: stale-plan penalty IMPLICIT − HYBRID** (healthy, delayed links).
  - Travel 0 shows a strong monotone increase with N:
    - d1, λ=1: 0.06, 0.11, 0.16, 0.26. Slope +0.085 per doubling, CI [+0.02, +0.14].
    - burst, λ=1: 0.03, 0.05, 0.10, 0.24.
  - Travel 1: small (0.00–0.06) with no clear trend.
  - This matches the 2-agent mechanism: same-step lock-step collisions, which travel time de-synchronises.
- **S3b: HYBRID_P − IMPLICIT. Against us at travel 0.**
  - At N ≥ 3 the priority-order rule leaves −0.04 to −0.11. For example, travel 0, burst, λ=1: −0.04, −0.06, −0.09, −0.11.
  - At travel 1 it is −0.06 to +0.03.
  - So the 2-agent fix (agent 1 predicts agent 0) does **not** fully scale.
  - Plausible cause: a lower-priority agent predicts *all* higher-priority deviated agents by sequential greedy from its own belief, and those predictions compound errors as N grows.
- **S2: loss, HEALTH vs ORACLE. Against us at N ≥ 3, travel 0.**
  - HEALTH − IMPLICIT, travel 0, λ=3, ideal: +0.04, −0.10, −0.04, −0.09.
  - Travel 1 is mixed: λ=1 ideal gives +0.03, +0.10, −0.03, −0.03.
  - Hypothesis (dev-generated, untested): with N − 1 survivors, the death frame makes *all* of them re-plan into the dead agent's gap at the same step, which is a herding effect absent at N = 2.
- **S4: loss, VoC = ORACLE − IMPLICIT.**
  - Positive at N = 2, roughly 0 or negative at N = 10. Travel 1, λ=3: +0.04, +0.09, +0.01, +0.04. Travel 0, λ=1: +0.04, −0.03, −0.03, −0.05.
  - This loosely fits "one agent's share shrinks". But VoC changes sign, which makes the power law c·N^−b ill-posed: in dev, b hits the grid bounds [−2, 3]. The linear-in-log2 N slope is the informative summary.
- **Value of the shared plan (IMPLICIT − INDEP)** grows with N at travel 0: 0.05, 0.28, 0.39, 0.33 (λ=1, healthy). At travel 1 it is flat at about 0.15–0.21.
- **HB_TO false alarms.** On the bursty link, HB_TO raises false death alarms. Outages are often longer than the K = 7 timeout, and there are N(N−1) directed pairs. This is pinned by a test (`test_hb_to_false_alarms_on_bursty_link`). Prop 1 therefore covers HB_TO on the ideal link only.

## 3. What dev says about the prereg hypotheses (not verdicts)
- **S1:** probably passes at N = 2–5 with the held-out E. At N = 10 the negative lean may break the ±0.03 margin.
- **S2:** at risk at N ≥ 3, because HEALTH can be harmful there.
- **S3a:** likely PASS at travel 0, FAIL at travel 1.
- **S3b:** likely FAIL at travel 0 from a real effect, not just CI width.
- **S4:** likely FAIL or uninformative, because VoC changes sign.
