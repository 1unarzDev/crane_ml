## 5. Proposed patch or decision (no code changed by this agent)

CONTRACTS forbid silently changing water dynamics or boat coefficients. Every water fix therefore goes behind an **isolated fixture/profile flag**, with an A/B comparison against the current behavior kept as the baseline.

1. **Hydro fixture profile `--crane-fossen-corrected`.** Negate added mass, or better, move M_A into the articulation inertia instead of feeding back ν̇. Route Coriolis rows 0-2 → force and row 5 → yaw moment, using skew-symmetric C_A. Use body-frame ω. Add a configurable body-from-FLU rotation (Blastoise −90°).
